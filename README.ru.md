# dns-shop-mcp

[English](README.md) · **Русский**

[MCP](https://modelcontextprotocol.io)-сервер, который отдаёт LLM-агентам живые и
честно подписанные данные магазина [DNS](https://www.dns-shop.ru) (dns-shop.ru):
поиск с настоящими страницами, сортировками, ценовым окном и фильтром наличия;
полную карточку товара для одного города; наличие по магазинам с разделением
упакованных экземпляров и витринных образцов; рейтинг и отзывы самого товара;
недельную историю цен.

> Сторона покупателя, анонимно: аккаунт DNS не используется. Ничего не кладётся в
> корзину и не заказывается.

## Зачем этот сервер

Цифры DNS легко прочитать неверно. Сервер построен так, чтобы этого не делать:

| Ловушка DNS | Что делает сервер |
|---|---|
| Любая динамическая страница отвечает 401 с JS-челленджем Qrator (proof-of-work) | Заход headless Chromium (≈1,5–2 с) получает куку `qrator_jsid2`; браузер закрывается, все данные идут обычным HTTP. На челлендж или 403 — один новый проход, затем понятная ошибка |
| Город зависит от клиента (по IP или Москва по умолчанию); цены и наличие в городах разные | Город ставится явно в каждом вызове (по умолчанию Екатеринбург) и сверяется с городом, который возвращают страница и виджет наличия; несовпадение — ошибка, а не данные |
| Рейтинг карточки и плитки у «мультикарточки» объединяет все варианты — цвета, память, даже разные аппаратные модели (iPhone 16: 2 268 отзывов на карточке, у чёрного 128 ГБ A3287 — 452) | `rating.shown_on_card` (scope «card») рядом с `rating.this_product`; флаг `merges_several_models` |
| Плитка округляет число отзывов: «2.3k отзывов» | Разбирается как ≈2300 с `reviews_approx: true`; точное число — из карточки |
| «В наличии в 13 магазинах» считает магазины, где есть только витринный образец | `stores_with_packaged_units` и `showcase_only_stores` по списку магазинов (сверено с окном «Наличие товара» на сайте) |
| «доп. скидка 1 600 ₽» действует только при онлайн-оплате (СБП); «Итого» остаётся 15 999 ₽ | `price_rub` — обычная цена; скидка отдельным полем, `price_if_paid_online_estimate_rub` подписана как оценка при условии |
| У товаров, которые DNS больше не продаёт, всё равно есть цена — **последняя цена продажи** | `not_sold: true`, `price_rub` нет, `last_sale_price_rub` отдельно |
| Товары маркетплейса «DNS Селлер» стоят в той же выдаче: другой продавец, 100 % предоплата, в магазинах DNS их нет | `seller` с юрлицом и ИНН, `prepayment_required` |
| Поиск молча сужается до одной категории и на этом редиректе теряет сортировку, ценовое окно и страницу; часть запросов уходит в каталог или на страницу бренда | Сервер повторяет запрос со всеми параметрами; `resolved_category`, `other_categories`; на запрос-бренд — категории бренда |
| «Сначала недорогие» не строго по возрастанию | Пересортировка по цене внутри страницы, порядок DNS — в `position`, об этом пишется в `notes` |
| Разные товары называются одинаково; «Модель» в характеристиках бывает общей («Apple iPhone 16») | `code` везде; `model` плюс `variant_specs` (например «A3287 (Nano-SIM + eSIM)») и все варианты мультикарточки |
| Устаревший токен страницы — и DNS отвечает «нет состояний», что выглядит как «нет цены» | Один повтор с обновлением, затем ошибка; никогда не выдаётся как «нет цены» |
| Стоимость доставки считается только в корзине | `delivery_cost_rub: null` с пояснением; есть только текст срока курьерской доставки |

В каждом ответе есть `fetched_at` (UTC) и `city` — id и название города, откуда
взят выбор и какой частью ответа DNS он подтверждён.

## Инструменты

| Инструмент | Что возвращает |
|---|---|
| `search_products(query, page, sort, price_min, price_max, availability, category, city, with_availability)` | 24 товара на страницу (задано DNS); сортировки `popular` / `price_asc` / `price_desc` / `rating` / `reviews` / `newest` / `discount`; наличие `any` (как на сайте по умолчанию, включая снятые с продажи) / `on_sale` / `in_stock` / `today` / `tomorrow` / `later` / `out_of_stock`. `resolved_category`, `other_categories`, `total_found_in_category`, `has_more`, диапазон цен категории и ценовые корзины DNS (на 1-й странице). По товару: код, название, краткие характеристики, поля цены, `not_sold` + `last_sale_price_rub`, `seller` маркетплейса, `avail_status`, сводка наличия и `stores_with_any_unit`, рейтинг карточки (scope «card»), метка надёжности, ссылка |
| `get_product(product, city, include_stores, include_price_history, include_characteristics)` | `product` — код, ссылка, 16-hex id или GUID. Цена (цена, до скидки, каждая скидка с условием, оценка при онлайн-оплате, платёж по кредиту, штатная гарантия и платное продление), продавец, наличие (магазины с любым экземпляром / с упакованным / только витрина, пункты выдачи, срок курьера, `delivery_cost_rub: null`), наличие по магазинам со временем получения, рейтинг карточки против рейтинга товара с распределением звёзд и оценками по аспектам, статистика надёжности DNS (доля без обращений в сервис, причины, среднее по категории), характеристики с «Моделью», описание, варианты мультикарточки, сводка истории цен, число вопросов |
| `get_reviews(product, page, limit, scope, sort, min_rating, max_rating, verified_buyers_only, with_photos, search, city)` | `scope` `product` (по умолчанию) или `multicard` (все варианты карточки); `sort` `newest` / `helpful` / `best`; фильтр по звёздам (`max_rating=2` — жалобы); фильтры DNS «реальный покупатель» и «с фото»; поиск по тексту отзывов. Дата, звёзды, достоинства, недостатки, комментарий, срок использования, купленный вариант, голоса, число фото; статистика для выбранного scope. Имён авторов нет |
| `get_price_history(product, city)` | Средние цены продажи DNS по неделям (≈24 недели) рядом с живой ценой; `current_week_is_partial` |
| `compare_products(products, city)` | До 24 товаров: один запрос цен и один запрос наличия на всех, плюс один запрос статистики отзывов на товар. Поля цены, флаги «не продаётся»/«предоплата», наличие, рейтинг самого товара и флаг мультикарточки |

Вопросы и ответы сознательно не собираются: они живут на club.dns-shop.ru, а
правила клуба запрещают автоматические скрипты.

## Требования

Замерено 2026-09-25 (Linux, домашний российский IP, Playwright 1.63, Chromium 1243):

| | |
|---|---|
| Python | ≥ 3.10, с [uv](https://docs.astral.sh/uv/) (или pip) |
| Браузер | Chromium от Playwright, скачивается сам при первом запуске в `~/.cache/ms-playwright` (≈660 МБ на диске: headless shell 261 МБ + Chromium 393 МБ как запасной режим; общий для всех инструментов на Playwright). Работает только на проход Qrator: 1,5–2,0 с, затем закрывается |
| Память | Пик ≈500 МБ (PSS сервера вместе с Chromium во время прохода Qrator); ≈75 МБ между проходами (только Python-сервер) |
| Холодный старт | `initialize` MCP 1,4 с; первый вызов инструмента добавляет проход Qrator (1,5–2 с) — первый поиск занял 13,7 с целиком |
| Длительность вызовов | Запросы идут с паузой 2 с: поиск 7–10 с (4–5 запросов), `get_product` 21–26 с (10–12; 12–15 с для товаров маркетплейса и снятых с продажи), `get_reviews` 3–7 с (1–3), `get_price_history` 5–9 с (3–4), `compare_products` ≈2 с × (2 + число товаров). Сам запрос — 0,1–0,35 с |
| Повторный проход | После ~15 мин без вызовов кука истекает (Max-Age 1000 с); следующий вызов проходит Qrator заново (+1,5–2 с) |
| Дисплей | Не нужен: всё работает headless |
| Docker | Не нужен |
| Системные библиотеки | Есть на десктопном Linux, macOS и Windows. На минимальном сервере Debian/Ubuntu поставить один раз (root): `uvx --from playwright playwright install --with-deps chromium` |
| Сеть | Российский IP без VPN: Qrator блокирует зарубежные, VPN- и датацентровые адреса. Или задать `DNS_PROXY` |
| Проверено на | Linux (CachyOS). macOS и Windows Playwright поддерживает, но не проверялись |

## Установка

Claude Code:

```bash
claude mcp add dns-shop -- uvx --from git+https://github.com/SZhukovWork/dns-shop-mcp dns-shop-mcp
```

Любой MCP-клиент (`claude_desktop_config.json`, `.mcp.json`, …):

```json
{
  "mcpServers": {
    "dns-shop": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/SZhukovWork/dns-shop-mcp", "dns-shop-mcp"]
    }
  }
}
```

Из рабочей копии: `uv venv && uv pip install -e . && .venv/bin/dns-shop-mcp`.

## Настройка (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `DNS_CITY` | Екатеринбург | Город по умолчанию: название как на сайте, `Название, Регион` для неоднозначных, slug города или его GUID. Каждый инструмент принимает и `city` |
| `DNS_MIN_INTERVAL` | `2.0` | Пауза между запросами к DNS, секунды; меньше 1,5 не бывает — поднимается до 1,5 |
| `DNS_PROXY` | — | Прокси для HTTP и браузера, например `http://user:pass@host:3128` |
| `DNS_CACHE_DIR` | `~/.cache/dns-shop-mcp` (`$XDG_CACHE_HOME/dns-shop-mcp`, если задан) | Сессия (кука, куки городов, токены страниц; файл 0600, каталог 0700) и справочник городов (обновляется раз в сутки) |
| `DNS_HEADLESS` | `1` | `0` показывает окно браузера во время прохода Qrator (отладка) |

## Что означают цифры

- **`price_rub`** — цена на dns-shop.ru в указанном городе для гостя (без входа),
  крупная цена карточки. `price_before_discount_rub` — зачёркнутая цена.
- **`online_payment_discount_rub`** — строка «доп. скидка». DNS применяет её только
  при онлайн-оплате заказа на сайте (воблер уточняет: СБП); «Итого» на карточке —
  обычная цена. `price_if_paid_online_estimate_rub` = цена − скидка, оценка при
  этом условии.
- **`credit_monthly_rub`** — платёж по кредиту или рассрочке, не цена.
- **`not_sold` / `last_sale_price_rub`** — DNS сейчас этот товар не продаёт;
  число — последняя цена продажи.
- **`prepayment_required`** — нужна 100 % предоплата (продавцы маркетплейса).
- **Рейтинги**: `rating.shown_on_card` — то, что показывает карточка, может
  объединять все варианты мультикарточки; `rating.this_product` — только этот
  товар. В плитках поиска — рейтинг карточки (`scope: "card"`).
- **Наличие**: `stores_with_any_unit` включает витринные образцы;
  `stores_with_packaged_units` — магазины с экземпляром в заводской упаковке;
  `showcase_only_stores` — только витрина. Время получения — местное время города,
  как его присылает DNS.
- **Надёжность** — собственная статистика DNS по проданным в её магазинах
  экземплярам без обращений в сервис; не данные производителя.
- **История цен** — средняя цена продажи за неделю («За прошедшие недели
  отображается средняя цена продажи»); последняя неделя — текущая, неполная.
  Зависят ли прошлые недели от города, не подтверждено (при сравнении Москвы и
  Екатеринбурга прошлые недели совпали, а текущие цены различались).

## Ограничения

- Неофициальный сервер: опирается на внутренние ручки и вёрстку сайта, которые DNS
  может поменять в любой момент. Разбор изолирован в `parse.py` и покрыт тестами
  на записанных ответах; при смене вёрстки поля пропадают, а не угадываются.
- `robots.txt` dns-shop.ru запрещает `/search/` и адреса с `?` для всех роботов;
  без них поиск невозможен. Частота запросов — человеческая (по умолчанию один
  запрос в 2 с), только для личного использования.
- Qrator может сменить челлендж; сборка Playwright, которая проходит сегодня,
  может перестать проходить. Привязка куки к IP не проверена.
- Нет персональных цен, бонусов ProZaPass и корзины: аккаунт не используется.
- Стоимости доставки нет (только в корзине) — есть только срок курьерской доставки.
- Уценённые экземпляры (`/catalog/markdown/`) не поддерживаются: `get_product`
  отказывает на их ссылки. На их странице показан рейтинг нового товара. Каталог
  уценки игнорирует поисковую фразу, для инструмента поиска нужно исследование.
- «Выгодные комплекты», слайдеры аксессуаров и аналогов не собираются.
- Вопросы и ответы не собираются (правила club.dns-shop.ru запрещают скрипты).
- iPhone: покупатели пишут об экземплярах, активированных до продажи; сервер лишь
  передаёт такие отзывы и проверить экземпляр не может.
- Сортировка поиска «Сначала с лучшей оценкой» — собственный порядок DNS, а не
  строгая сортировка по показанному рейтингу; `get_reviews(sort="best")` — сначала
  с наибольшим числом звёзд.

## Планы

- Необязательный режим аккаунта (персональные цены, бонусы) и корзина — позже.
- Поиск по уценке — нужно доисследовать каталог уценки.
- Оформление заказа, оплата и смена адреса — вне планов.

## Разработка

```bash
uv venv && uv pip install -e '.[dev]'
.venv/bin/pytest            # офлайн-тесты на записанных обезличенных ответах
.venv/bin/pytest -m live    # сквозной прогон по MCP stdio против живого dns-shop.ru (российский IP, ~30 запросов)
```

## Оговорка

Сервер не связан с DNS. Он использует недокументированные внутренние ручки сайта
и проходит его антибот-проверку настоящим браузером. Предназначен для личного
поиска выгодной цены с человеческой частотой запросов; соблюдайте условия
использования DNS.
